# Diabetes Prediction Using Support Vector Machines

A machine learning project that uses a Support Vector Machine (SVM) to classify diabetes outcomes based on numerical health measurements.

## Project Overview

This project explores supervised learning using the Pima Indians Diabetes Dataset. The workflow includes data preparation, feature scaling, model training, and evaluation.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook / Google Colab

## Project Workflow

1. Load and explore the dataset.
2. Separate input features and outcome labels.
3. Split the data into training and testing sets.
4. Fit feature scaling on the training data.
5. Train the SVM classifier.
6. Evaluate predictions on the test data.

## Dataset

The **Pima Indians Diabetes Dataset** includes eight input features: pregnancies, glucose, blood pressure, skin thickness, insulin, BMI, diabetes pedigree function, and age.

The target variable is `Outcome`: **0** for a negative diabetes outcome and **1** for a positive outcome.

## Evaluation

Relevant metrics include accuracy, precision, recall, F1-score, and a confusion matrix. Verified results will be added after running and reviewing the notebook.

## How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Make the dataset available and update its path in the code.
3. Install any missing dependencies.
4. Run the cells in order and review the outputs.
